
SpeakBuddy — 英语口语练习工具 需求文档（v2）

---

## 一、项目概述

SpeakBuddy 是一个浏览器端的英语口语练习工具。用户可以选择对话场景（面试 / 点餐 / 会议），通过浏览器语音识别与 AI 进行实时语音对话。系统采用双角色 LLM 架构，一次调用同时生成对话回复和学习评估，提供语法纠错、词汇建议和评分。

## 二、技术栈

### 前端
- React 18 + TypeScript + Vite
- Tailwind CSS (通过 @tailwindcss/vite 插件)
- 状态管理：Zustand
- 语音识别：浏览器 Web Speech API（免费，Chrome/Edge 支持）
- WebSocket 通信：原生 WebSocket

### 后端
- 运行时：Node.js + tsx
- 框架：Hono，集成 WebSocket 支持 (@hono/node-server 和 @hono/node-ws)
- API 集成：小米 MiMo 开放平台（https://platform.xiaomimimo.com）
  - LLM 对话：mimo-v2-flash（一次调用，同时返回对话回复 + 学习评估 JSON）
  - TTS 语音合成：mimo-v2.5-tts（voice: Chloe，输出 wav）
- 对话历史保存在内存中

## 四、核心功能与实现细节

### 4.1 场景选择
- 三个场景：面试 (interview)、点餐 (ordering)、会议 (meeting)。
- 点击场景按钮时，通过 WebSocket 发送 `{ type: 'set_scenario', scenario: '...' }`。
- 后端收到后更新对话角色提示词，并清空历史。

### 4.2 语音对话流程
1. 用户点击麦克风按钮，调用浏览器 Web Speech API（webkitSpeechRecognition）开始录音。
2. 再次点击停止录音，浏览器返回识别文本。
3. 前端通过 WebSocket 发送 `{ type: 'user_speech', text: '...' }` 给后端。
4. 后端调用 MiMo LLM，一次请求同时返回对话回复和评估数据（JSON 格式）。
5. 后端发送三条消息给前端：
   - `{ type: 'user_text', text: '...' }` — 用户识别文本
   - `{ type: 'ai_text', text: '...' }` — AI 对话回复
   - `{ type: 'ai_evaluation', evaluation: { ... } }` — 评估数据
   - 二进制：TTS 语音音频 (wav)

### 4.3 双角色 LLM 设计
核心设计：一个模型同时驱动对话和评估，减少 API 调用链路。

System Prompt 要求模型返回 JSON：
{
  "reply": "对话回复（2-3句，自然的场景对话）",
  "evaluation": {
    "corrected": "用户原话的语法纠正版本",
    "grammar": [
      { "original": "错误片段", "corrected": "正确写法", "explanation": "语法规则说明" }
    ],
    "vocabulary": [
      { "suggestion": "更好的用词", "context": "为什么更好，附例句" }
    ],
    "score": { "fluency": 7, "grammar": 6, "vocabulary": 7, "overall": 7 },
    "comment": "一句具体的鼓励和建议"
  }
}

纠错时机：延迟纠错 — 评估数据以折叠卡片形式展示，用户自行点击展开查看，不打断对话流。

### 4.4 WebSocket 消息协议
**前端 → 后端：**
- 设置场景：`{ "type": "set_scenario", "scenario": "interview" }`
- 语音文本：`{ "type": "user_speech", "text": "..." }`

**后端 → 前端：**
- 连接就绪：`{ "type": "ready", "message": "Connected" }`
- 用户文本：`{ "type": "user_text", "text": "..." }`
- AI 回复：`{ "type": "ai_text", "text": "..." }`
- AI 评估：`{ "type": "ai_evaluation", evaluation: { ... } }`
- 场景已设置：`{ "type": "scenario_set", "scenario": "..." }`
- 二进制：AI 语音回复 (wav)

### 4.5 前端组件行为
- **App.tsx**：顶部 ScenarioSelector，中间聊天列表（自动滚动），底部麦克风按钮（点击切换录音）。
- **ChatBubble.tsx**：用户消息靠右蓝色，AI 消息靠左灰色。AI 消息下方集成 CorrectionCard。
- **CorrectionCard.tsx**：折叠状态显示评分摘要（颜色标识高/中/低分），点击展开显示：评分四维（流畅度/语法/词汇/综合）、纠正版本、语法纠错列表、词汇建议、总评。
- **useSpeechRecognition.ts**：封装浏览器 Web Speech API，配置 en-US，单次识别。

### 4.6 环境变量
MIMO_API_KEY=你的小米MiMo API Key

### 4.7 启动方式
# 后端
cd backend && npm install && npm run dev

# 前端
cd frontend && npm install && npm run dev

# 打开 http://localhost:5173

### 4.8 关键设计决策
- 语音识别使用浏览器内置 Web Speech API，免费无需额外 API。
- LLM 使用小米 MiMo 平台，一个 API Key 驱动对话 + TTS。
- 双角色 prompt：对话伙伴（自然回复）+ 隐形评委（JSON 评估），一次调用完成。
- 纠错时机为延迟纠错：评估以折叠卡片展示，不打断对话流。
- 对话历史中只存储 reply 文本，不含评估数据。
